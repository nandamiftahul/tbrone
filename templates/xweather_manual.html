0) Quick Start – Tampilan Utama & Tombol Penting

Tujuan: mengenali lokasi menu untuk Add Asset, Map Layers, dan kontrol replay.

Xweather Protect
1

Buka halaman Map

Masuk ke Xweather Protect → pilih tab Map. Pastikan Anda sudah login.

2

Kenali tombol Add dan Map layers

Tombol Add dipakai untuk menambahkan Asset. Tombol Map layers dipakai untuk menampilkan ring alert dan layer petir.

3

Kenali timeline replay

Kontrol replay (tanggal, play/pause, timeline) berada di bagian bawah map untuk melihat ulang kejadian beberapa hari terakhir.

1) Cara Menambahkan Asset (Protected Area)

Membuat area proteksi (asset) berupa circle/area operasi yang akan dipantau petirnya.

Setup
1

Klik tombol Add

Di halaman Map, klik Add (pojok kiri atas) → pilih opsi untuk menambahkan asset/protected area.

2

Pilih tipe asset (icon)

Pilih tipe asset yang paling sesuai (mis. site/area). Ini hanya untuk identifikasi visual pada daftar asset.

3

Tentukan lokasi & bentuk area

Klik pada peta untuk menempatkan pusat area. Jika menggunakan circle, atur radius sesuai kebutuhan. Pastikan area mencakup pit/working area yang ingin diproteksi.

4

Simpan asset

Isi nama asset (contoh: ZONE01) → klik Save. Asset akan muncul di panel daftar asset.

5

(Opsional) Upload file JSON/GeoJSON

Jika Anda memiliki boundary area dari GIS, gunakan fitur upload JSON/GeoJSON agar bentuk area lebih presisi.

Catatan: Jika subscription Anda membatasi jumlah protected assets, pastikan jumlah asset yang dibuat sesuai lisensi aktif.
Bagaimana cara menghapus asset?

Buka daftar asset → pilih asset yang ingin dihapus → klik menu aksi (trash/delete) → konfirmasi.

2) Cara Menambahkan Alert/Alarm (Rings + Forecast)

Mengatur ring Info/Warning/Alarm, clear time, dan (opsional) forecast advance time.

Alerts
1

Pilih asset yang ingin diatur alert-nya

Di daftar asset, klik asset (mis. ZONE01) → masuk ke halaman konfigurasi alerts.

2

Aktifkan Real-time lightning

Pada menu alerts, pastikan Real-time lightning aktif. Ini adalah engine utama untuk ring Info/Warning/Alarm.

3

Set Alarm ring

Atur radius Alarm (mis. 4 km) dan Clear time (mis. 15 menit). Alarm biasanya dipakai untuk "stop operation" sesuai SOP.

4

Set Warning ring & Info ring

Atur radius Warning (mis. 10 km) dan Info (mis. 20 km), termasuk clear time masing-masing. Warning untuk pembatasan, Info untuk monitoring awal.

5

(Opsional) Aktifkan Forecast lightning

Masuk ke Forecast lightning → set alert lead time (10–60 menit). Ini memberi estimasi kapan storm/aktivitas petir akan tiba di asset.

6

Simpan konfigurasi

Klik Next / Save sampai selesai. Pastikan ring terlihat pada map sebagai verifikasi.

Best practice: Gunakan radius ring mengikuti SOP keselamatan. Clear time umum (contoh 15 menit) memastikan status kembali "clear" setelah periode tanpa event petir.

3) Cara Monitoring Alarm yang Sudah Dibuat

Melihat status severity, memeriksa petir di ring, dan mengunduh laporan alert.

Operations
1

Aktifkan layer ring & petir

Klik Map layers → aktifkan Severe weather → centang Lightning alert rings dan Lightning event time.

2

Pilih range waktu (mis. Last 60 minutes)

Pada panel layer, pilih Last 60 minutes atau Last 30 minutes agar event petir terbaru terlihat.

3

Klik titik petir untuk detail

Klik titik petir pada peta untuk melihat popup detail seperti tipe (CG/CC), umur event, dan strength (kA) – ini membantu validasi manual.

4

Validasi ring mana yang ter-trigger

Bandingkan posisi titik petir terhadap ring: masuk Alarm → status Alarm; masuk Warning → status Warning; masuk Info → status Info.

5

Unduh laporan 30-day lightning alerts (CSV)

Gunakan tombol download pada halaman alerts report untuk mendapatkan CSV log alert: waktu mulai, waktu clear, durasi, dan severity.

Catatan operasional: Jika customer menggunakan 3 zona besar, maka validasi detail per area kecil dilakukan secara manual dengan melihat posisi petir relatif terhadap ring/area operasional.

4) Cara Melihat / Replay Data Weather Secara Manual

Gunakan 7-day replay untuk memutar ulang kejadian (post-event analysis).

Replay
1

Buka timeline replay

Di bagian bawah map, pilih rentang tanggal (mis. hari ini – 7 hari terakhir). Pastikan mode replay aktif.

2

Gunakan Play / Pause

Klik tombol play untuk memutar kejadian. Gunakan pause untuk berhenti pada waktu tertentu ketika terjadi petir yang memicu alert.

3

Geser pointer waktu

Geser slider pada timeline untuk loncat ke jam/menit tertentu. Ini efektif untuk mengecek kapan status berubah dari Info → Warning → Alarm.

4

Verifikasi dengan ring & event layer

Tetap aktifkan layer ring & event petir agar selama replay Anda bisa melihat petir masuk ring mana, dan kapan all clear terjadi.

Tips: Jika perlu bukti visual untuk meeting internal, replay dapat direkam dengan screen recorder (Xweather tidak menyediakan fitur perekaman video bawaan).

5) Fitur Tambahan yang Sering Terlupa

Fitur pendukung operasi: notifikasi, filter tipe petir, dan praktik terbaik konfigurasi.

Extras
1

Notification Lists

Buat daftar penerima notifikasi (email/SMS sesuai paket) agar tim HSE/ops menerima informasi saat status berubah.

2

Filter tipe event (CG only vs All events)

Pada Map layers, pilih CG only jika hanya ingin menampilkan petir cloud-to-ground sesuai kebutuhan SOP.

3

Cloud-to-Cloud option

Pada konfigurasi ring, Anda dapat mengaktifkan opsi cloud-to-cloud jika dibutuhkan untuk awareness lebih luas (tergantung kebijakan keselamatan).

4

Audit operasional dengan CSV (30-day alerts report)

Gunakan CSV untuk laporan downtime: Severity, waktu mulai, waktu clear, dan durasi. Ini membantu korelasi produksi menurun dengan alert petir.

5

Verifikasi lisensi & jumlah protected assets

Cek subscription (jumlah protected assets aktif). Jika asset melebihi limit, beberapa area tidak bisa diproteksi secara real-time.

Reminder: Pastikan SOP internal (shutdown, stand-by, resume) selaras dengan ring radius dan clear time yang dikonfigurasi.
