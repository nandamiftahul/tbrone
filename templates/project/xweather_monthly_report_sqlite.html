    Legend & Penjelasan Kolom

    Ringkasan arti kolom pada laporan dan aturan severity.

    Help
    Severity: Info (monitoring awal), Warning (lebih dekat), Alarm (zona kritis/SOP stop).
    • Extent (km): radius ring/area yang ter-trigger (contoh: 20 km / 10 km / 4 km).
    • First event time: waktu pertama kali event petir memicu severity itu.
    • Active time: waktu status mulai aktif (umumnya sama dengan first event time).
    • Last event time: waktu event petir terakhir sebelum status menuju clear.
    • Clear time: waktu status kembali aman setelah tidak ada event (mengikuti clear time setting).
    • Duration (min): total durasi status aktif (menit).
    • Strength (kA): kekuatan petir (kiloampere), biasanya peak current.
    • Type: tipe petir (misal CG-, CG+, dst).

    Date/Time Format

    Pilih format tampilan waktu di tabel.

    Catatan: Pilihan ini hanya mengubah tampilan waktu di layar agar mudah dibaca oleh pengguna laporan.
    Tip Excel: gunakan format Excel friendly supaya kolom waktu langsung dikenali sebagai DateTime.
