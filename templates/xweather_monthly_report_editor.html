Monthly Report Editor

Input / edit data report bulanan. Data tersimpan otomatis di LocalStorage (tidak hilang saat refresh). Bisa import/export CSV.

Editor
Severity Asset name Extent (km) First event time Active time Last event time Clear time Duration (min) Strength (kA) Type Actions
Catatan: Editor ini client-side. Kalau nanti mau “shared ke semua user” (server-side), kita bisa pindah storage ke DB + API (Flask).

Tips & Format CSV

Header CSV harus mengikuti urutan kolom berikut supaya import sukses.

Help
CSV Header:
Severity, Asset name, Extent (km), First event time, Active time, Last event time, Clear time, Duration (min), Strength (kA), Type
  • Severity: Info / Warning / Alarm (case-insensitive)
  • Time format: bebas (mis. 05.01.2026 06:13 atau 2026-01-05 06:13)
  • Kalau ada koma dalam text, CSV harus pakai tanda kutip ("...").
